2. CHẠY PYTHON
Giải nén toàn bộ gói trước khi chạy; giữ cấu trúc thư mục.
Mở thư mục bộ nộp trong VS Code/Jupyter, chọn kernel Python có numpy, pandas,
matplotlib, ipykernel. Cài thư viện nếu cần: python -m pip install -r requirements.txt
Thư mục làm việc của notebook có thể là thư mục gốc hoặc python/.
Chạy Run All trong từng notebook theo thứ tự phần việc.
Đồ thị nằm ở notebook 25 đến 39; kết quả tiền xử lý đã có trong ket_qua/.

Không xóa ba file .py sau:
- 01_kiem_tra_du_lieu.py: notebook 01 gọi thuật toán khảo sát trong file này.
- 04_dien_null.py: notebook 04 gọi quy trình điền thiếu tổng hợp trong file này.
- 22_xuat_after.py: notebook 22 dùng để ghép kết quả và đối chiếu hai after.
Notebook 04 là bản tổng hợp bổ sung; notebook 05–11 trình bày từng quy tắc
N01–N07 đúng với minh chứng từng phần trong báo cáo.
Các file .py dựng/chỉnh Word, __pycache__ và bản Word cũ không đưa vào bộ nộp.
Chạy lại notebook có thể cập nhật file kết quả trong ket_qua/ và after_Python;
original và before phải được giữ nguyên.

3. CHẠY SQL
Cần SQL Server (khởi chạy qua docker compose up -d) và VS Code (extension MSSQL). Cơ sở dữ liệu dùng trong bài là HeartFailure_DoAn.
Nhập before vào dbo.heart_before_raw dạng nvarchar(50), cho phép NULL trên
cả 13 cột để không làm mất chuỗi Invalid_Age.
Các bước dùng bảng tạm phải chạy trong cùng tab/kết nối SQL.
query_dataanalyst.sql có các bước EF và tổng hợp tám nhóm; hai file SQL rỗng
03h_dien_null_ejection_fraction.sql và 08b_giam_so_dong_tong_hop.sql được bỏ
khỏi gói vì không chứa code. Không xem các file từng phần là một pipeline tự
động; xem hướng dẫn/comment đầu mỗi file và bản truy vấn tổng hợp.
sql/10_xuat_after.sh là công cụ xuất SQL thuần macOS/Linux, kết nối container sql_doan (localhost,1433, user sa); chỉnh biến môi trường MSSQL_SA_PASSWORD nếu đổi mật khẩu.
Thống kê sau xử lý dùng bảng dbo.heart_after nhập từ after_SQL như báo cáo.
